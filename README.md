2. Project Objective
What is the purpose of this project?
"The objective of the Student Marks Analyzer is to create a simple Python-based system that accepts marks for different subjects and automatically
calculates the student's total marks, average marks, highest-scoring subject, lowest-scoring subject, and overall grade."
This demonstrates your understanding of Python data structures, loops, conditional statements, and built-in functions.
